# kaoyan v0.4.0

考研择校的**体检工具**：把「这所学校这个专业到底好不好考」拆成能被官方数据回答的问题，并把答案写成一张不需要内行解释就能读的纸。

不是择校指南，不是院校排名，也不是「AI 帮你选学校」。它只做一件事：**从官方文件里把数字挖出来，按固定规矩判断，缺什么就明说缺什么。**

## 它想解决的五个信息差

| # | 大多数人这么看 | 实际是这样的 |
|---|---|---|
| 1 | 「计划招 101 人，挺多」 | 深大 085404 计划 101，但推免占了 96，**统考只剩 29** |
| 2 | 「去年分数线多少」 | 分数线的趋势不如**推免占比的趋势**能预测明年（深大 38%→77%） |
| 3 | 「复试线等于国家线，应该不难」 | 深大 085404 复试线 **347**，国家线 273；校线≠院线≠专业线 |
| 4 | 「深大计算机招 96 人」 | 同一专业代码在四个招生单位是**四个池子**（31/14/45/6），不能相加 |
| 5 | 「等出分再查名单」 | 拟录取名单只挂 **7 天**，过了附件全撤，均分再也查不到 |

## 它明确不做什么

- **不做院校排名。** 没有全国统一的、可复核的质量数据，任何名次都是编的。
- **不代猜。** 估分、冲稳保要考生自己给数；脚本不替用户做决定。
- **不假装全自动。** 每所学校首次要人工给一个招生目录入口页（研招网不提供官网链接），给过就记住。
- **不绕过任何限制。** 遇到验证码、登录墙、412 就停下并说明，不重试、不硬闯。

## 实测成功率（先说清楚，再谈功能）

`scripts/selftest.py` 对 8 所已验证入口页抽样（2026-11-01，专业代码 085401）：

| 环节 | 成功 | 比例 |
|---|---|---:|
| 抓取页面 | 8/8 | 100% |
| 下载到附件 | 3/8 | 38% |
| 解析出表格 | 4/8 | 50% |
| **认出专业代码列（可出报告）** | **4/8** | **50%** |

能出报告的 4 所：杭电（附件）、西电（附件，198 张表）、山大（附件）、深大（入口页 HTML 表）。
失败的 4 所全部是**已知硬障碍**，不是脚本 bug：南开（seed 指向列表页）、中南（目录在独立系统）、吉大（附件验证码）、重邮（官网全站 412）。

**结论：它覆盖「专页式 / PDF 式 / HTML 表」三类学校，覆盖不了验证码、登录系统、全站 WAF 三类。** 这两句必须一起看。

## 4 专业 × 5 校 实测（2026-11-01，20 次）

`scripts/matrix_test.py` 的跑批结果 —— **成功 12/20**：

| 学校 | 成功 | D 范围 | 数据形态 | 结论 |
|---|---:|---|---|---|
| 杭州电子科技大学 | **4/4** | 0.58–0.69 | PDF（2024-2026 报考上线录取情况）+ HTML 复试线 | 唯一能给出完整三年趋势的样本 |

| 西安电子科技大学 | **4/4** | 0.06–0.09 | PDF 招生目录（只有计划数） | 能跑，缺录取分布 |
| 山东大学 | 0/4 | — | 目录锁 CAS；页面上只有**学科门类级**复试线（`[08]工学`） | 6 位专业代码匹配不到门类线 |

这轮跑批同时修掉三个问题（见 `CHANGELOG.md` v0.2.3）：内嵌 PDF 漏抓、`html5lib` 依赖缺失、把「有数据但拆不开」错报成「没找到」。

## 怎么用：把它交给 agent，你不用跑命令

这个 skill 是**给大模型 / agent 用的**。`scripts/` 下的一切是它的手——查页面、下 PDF、解析表格、算指标都由它执行。
作为学生，你只需要：**回答问题**、**在它拿不到时给一个链接**。
下文出现的命令是给 agent 看的执行细节，不是让你抄的作业。

## 推荐模式：七步走（一无所知也能开始）

从"我只有一个本科专业"开始，不要求你先知道目标校：

| 步 | 做什么 | 命令 |
|---|---|---|
| 0 | 时间线：哪年考、几年级、跨不跨考 | 写进 `assets/profile.md` |
| 1 | **专业画像**：读研干什么 / 能读博吗 / 毕业去哪 | `python scripts/major_profile.py --code 085401` |
| 2 | 科目：政治 / 英一二 / 数一二三 / 专业课代码 | 随 `check.py` 从目录抽；抽不到给检索式 |
| 3 | 圈范围：目标校、城市、省份 | 问一次写进 `filters.json` |
| 4 | 学科信号：双一流学科 / 博士点 / 第四轮等级 | 逐校查（不编名次） |
| 5 | 收敛：可得性 → 风险信号 → 你的约束 | `python scripts/recommend.py --city 杭州 南京 --major 085401` |
| 6 | 深查：3-5 所体检报告 | `python scripts/check.py ...` |
| 7 | 钱和住：校区 / 学费 / 宿舍 | 按 `references/life.md` 逐校查 |

**科目先行**，不是名单先行：先用初试科目砍掉一半范围，再谈学校。

`recommend.py` 支持三种起点：`--schools 杭电 南邮`（有目标校）/ `--city 杭州 上海`（只有城市）/ `--undergrad-major 电子信息工程`（只有本科专业）。
输出只分三层，**不做排名**：能不能查到 → 信号亮不亮 → 符不符合你的约束。

## 快速开始

```powershell
# 0) 装依赖（Python 3.9+）
pip install requests pandas pdfplumber openpyxl xlrd lxml html5lib

# 1) 自检：一次跑完七项检查，比报错后猜原因快
python scripts/doctor.py

# 2) 建议把数据放到单独目录，别写进 skill 本体
$env:KAOYAN_HOME = "D:\kaoyan-data"

# 3) 专业画像（第 1 步）：先搞清楚要考的这个专业读研干什么
python scripts/major_profile.py --code 085401 --init
python scripts/major_profile.py --code 085401 --check   # 还缺哪几项、去哪找

# 4) 建招生单位池（全国 936 所，按省市）
python scripts/pool.py --province 浙江 江苏 上海

# 5) 收敛出下一步该查哪几所（不做排名）
python scripts/recommend.py --province 浙江 江苏 上海 --major 085401

# 6) 按条件筛短名单（先按 references/intake.md 引导用户，答案写进 filters.json）
python scripts/screen.py --province 浙江 江苏 --major 085401

# 7) 对重点校深查 → 体检报告
python scripts/check.py --school 杭州电子科技大学 --major 085401 `
    --seed "<该校招生目录页 URL>" --extra "<该校复试线页 URL>"
```

`data/seeds.builtin.csv` 里有 8 所已验证入口页，首次可以先拿它们练手：

```powershell
python scripts/check.py --school 杭州电子科技大学 --major 085401   # seed 已内置
python scripts/check.py --school 深圳大学 --major 085404           # 只有 HTML 表也能跑
```

**两条路径自动选**：入口页有 PDF/Excel 附件 → 走附件解析；只有 HTML 表 → 自动把入口页（含 `--extra`）当表格解析。两者都没有时才报错，并说明该换数据源还是该人工读数。

## 判读规矩（代码里强制，不是建议）

1. **`unknown` 不是 0。** 判不了的信号记「待核」，全待核 → `⚪ 未知（数据不足）`，绝不显示成绿色。
2. **可判度 = D × S，分母固定。** D = 已填格 ÷（**八项** × 年数 × 招生单位数）——**缺失字段不许剔出分母**，只分两类展示：`unknown`（有列无值）与 `n/a`（整份材料无此列）。S 为来源层级（全 L1/L2 → 1.0，掺 L3 → 0.85）。**L1 来源不足 2 条时，置信度封顶「中」**（硬门槛，不随分数上浮）。八项 = 计划 / **统考名额** / 推免 / 一志愿录取 / 上线 / 复试线 / 均分 / 报考。
3. **同一专业代码多个招生单位，全部并列。** 复试线多口径取最高为主值，其余照抄，绝不静默取一行。
4. **阈值标注「经验值，未回测」。** 报告里只写「信号亮了」，从不写录取概率。
5. **可疑数字回原文核对。** 报告带来源清单（URL + 发布日期 + 访问日期），发现异常先看原文，再记进台账 `note`。

## 隐私与礼貌

- 只抓公开页面；不绕过登录、验证码、付费墙
- 只取汇总数字（学院/专业代码/人数/分数）。命中疑似**含考生姓名**的名单文件时**不落盘**，只记链接并在报告里列出 —— 该规则在 `check.py` 与 `fetch_school.py` **两个入口都生效**
- 默认 0.3 秒/请求、单次最多 8 个页面；批量使用请自行调大间隔
- 原始数据版权归各招生单位 / 教育部，本工具不主张任何数据所有权

详细条款见 [LICENSE](LICENSE) 末尾的「数据使用声明」。

## 已知边界（v0.2）

1. **每所首次要人工给入口页** —— 研招网院校库不给官网链接，这道坎在数据源那边
2. **研招网专业目录接口需登录，且登录后仍拒绝**（实测三种打法全部失败），「跨校统一底表」不存在
3. **扫描件 PDF / PNG 表格**不自动解析（需人工或视觉读数）
4. **验证码附件、CAS/SPA 目录、全站 412** 三类学校覆盖不了 —— 这是抽样里那 50% 失败的原因
5. **阈值未回测** —— 见 `thresholds.md` 第四节的回测计划
6. **数据有保质期** —— 每年 9 月新简章发布后要复核；名单类数据只有 7 天寿命
