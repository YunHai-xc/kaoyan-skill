# 出错怎么办

脚本的每一条错误信息都能对到这里的某一行。先看「症状」，再看「它其实在说什么」。

## 一、启动就挂

| 症状 | 它其实在说什么 | 怎么办 |
|---|---|---|
| `ModuleNotFoundError: No module named 'pandas'`（或 requests/pdfplumber/openpyxl/xlrd/lxml） | 依赖没装 | `pip install requests pandas pdfplumber openpyxl xlrd lxml`，然后 `python scripts/doctor.py` |
| 中文全是 `锟斤拷` 或 `??` | Windows 终端默认 GBK | PowerShell 里 `$env:PYTHONIOENCODING="utf-8"`；或先跑 `doctor.py` 看第 3 项 |
| `PermissionError` 写不进 `data/` | 数据目录在只读位置（或受管控目录） | 设 `KAOYAN_HOME` 指到可写目录，例如 `$env:KAOYAN_HOME="D:\kaoyan-data"` |
| `xlrd` 相关报错，但文件是 `.xlsx` | 旧版 `.xls` 和 `.xlsx` 不是同一个解析器 | `.xls` 需要 `xlrd>=2.0`；`.xlsx` 需要 `openpyxl`。都装上 |

## 二、`check.py` 的三类失败

### `抓取失败：一个页面都没抓到`

- 网络不通，或这个地址在你的网络下不可达
- 该校有反爬（返回 412 / 403），脚本最多试两次就停，不硬闯
- 处置：浏览器里打开这个地址确认能看；能看就是反爬，换学院站或研招网镜像；仍然不行就记 `unknown`，不要绕

### `这页没有可解析的附件（PDF/Excel）`

四个常见原因，按顺序排查：

1. **数据在 HTML 表格里** → 用 `--extra` 直接把那一页给进来（脚本会解析 HTML 表）
2. **数据是图片 / 扫描件**（深大、山大都是这种）→ 脚本管不了，需人工读数，规则见 `pipeline.md`「障碍处置」第 1 条
3. **这页不是「录取情况 / 招生计划」页** → 换成招生目录页、公示页再试
4. **附件挂了验证码**（吉大、中南）→ 脚本会把链接列出来，需人工下载

### `没在附件里找到专业代码 XXX 的任何一行`

- **代码不对**：`085404` 和 `085401` 是两个完全不同的方向，别混
- **表格把代码写成「085404计算机技术」并做了换行截断** → 打开 `.cache/check-*/assets/` 手工看一眼
- **该校今年这个专业不招**，或只招非全 / 只在另一个招生单位

## 三、报告看着不对劲

| 现象 | 原因 | 处置 |
|---|---|---|
| 复试线显示 `—`，但你知道有 | 复试线常单独发一张 HTML 表 | 加 `--extra "<复试线页URL>"`；页面 URL 里要含年份（`/2026/`）才能归到对应年 |
| 报告里写着「招生单位：4 个」 | 同专业代码在不同单位是不同池子（深大就是 4 个） | 正常，别把几个池子的名额相加 |
| 风险等级是 `⚪ 未知（数据不足）` | 多数信号判不了 | 不是「没风险」。补齐年份或换数据更全的入口页 |
| 可判度很低（< 0.45） | 缺的格子多，或数据来自非官方 | 按报告「缺格」那一行去补；别拿低可判度的结论做决定 |

## 四、`screen.py` 相关

| 症状 | 原因 | 处置 |
|---|---|---|
| `池子是空的` | 还没建池 | `python scripts/pool.py --province 浙江` |
| 筛出几百所，没法用 | 池子只到「学校 × 省份 × 双一流」 | 正常。先查 4 所重点校，不要指望工具替你排名 |
| 名单里没有某所学校 | 它可能不在研招网院校库，或省份名写错 | 用 `--province` 里的官方省名（如「内蒙古」不是「内蒙」） |

## 五、数据准确性

**脚本不做人工核对。** 它只保证：
- 每一条数字有来源链接和抓取日期
- 缺的格子记 `unknown`，不补 0
- 同一个代码多个招生单位时全部并列，不静默取一条

**它不保证**：
- 官方表格本身没印错（我们遇到过学校自己的「国家线」列填错年份）
- 你手上的年份对（记得 `--extra` 的 URL 里带年份）

发现数字可疑时，正确动作是**打开报告「来源清单」里的链接自己看一眼**，然后把差异记进台账的 `note`，不要直接改数字。
