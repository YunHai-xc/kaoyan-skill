# 普适取数：不认学校，只认四层动作

目标：**给一个学校名 + 专业代码，就能把七项数据挖出来**，不用为每所学校写特例。

做法是把「学校差异」从流程里赶出去 —— 差异只存在于表头和排版，所以差异全部收敛到第 3 层的**归一化动作**里，前两层完全不看学校。

```
① 定位          ② 抓取            ③ 解析            ④ 入库
站点 + 栏目  →  页面遍历 + 附件  →  拆表 + 认列   →  校验 + 台账
（人工/搜索引擎）（fetch_school.py）（extract_tables.py）（validate + 抽样核对）
```

## ① 定位：先找站点，别猜域名

学校的研招站点前缀不统一，实测同一批学校就有 `yz` / `yzb` / `grs` / `gra` / `yjs` 五种；学院站还常在另一台主机（深大研招 `yz.szu.edu.cn`、计算机学院 `csse.szu.edu.cn`；山大计算机是 `cs.`，而 `cse.` 是密码科学与工程学院）。

固定动作：

1. 搜索「<学校> 研究生招生 硕士 2027 专业目录」，从结果里拿域名，不要套模板
2. 站点内按关键词找栏目：**招生简章 / 专业目录 / 复试录取 / 拟录取公示 / 推免**
3. 进入「拟录取公示」栏先看有没有**统考计划专页**（发布形态见 `school.md` 第二节）

## ② 抓取：`scripts/fetch_school.py`

```powershell
python scripts/fetch_school.py --seed <种子页URL> --out out/<校名> --max-pages 80
```

它只做三件与学校无关的事：

- 同域名 BFS，只跟进标题/锚文本命中「招生/简章/目录/复试/录取/推免/调剂/计划/名单」的链接
- 挑出附件链接（`.pdf/.xls/.xlsx/.png`，或 `download.jsp` / `virtual_attach_file` / `wbfileid` 这类下载口）
- **按文件头判真实类型**（不信 Content-Type）：PDF 看 `%PDF`，PNG 看 `\x89PNG`，xls 看 `\xD0\xCF`，xlsx 看 `PK`

输出 `manifest.json` + `assets/`，每条附件记 `url / kind / bytes / sha256 / needs_manual`。

**验证码自动识别**：下载回来的东西不是文件（是 HTML）且正文含「请输入验证码 / 统一身份认证 / 环境异常」→ 标 `needs_manual`，不再重试。

## ③ 解析：`scripts/extract_tables.py`

```powershell
python scripts/extract_tables.py --file out/xidian/assets/02-2027pdf.pdf --out out/xidian/tables --major 085404
python scripts/extract_tables.py --url http://grs.hdu.edu.cn/2026/0324/.../page.htm --out out/hdu/tables --major 085404
```

支持四种形态：**PDF**（pdfplumber 逐页拆表，无表则退回按行切文本）、**Excel**（pandas 全 sheet）、**HTML**（read_html）、**图片**（不走脚本，下载后用视觉直接读，见 `school.md` 第十二节）。

### 归一化：学校差异全在这一步被吃掉

| 现实里的坑 | 脚本怎么处理 |
|---|---|
| 表头藏在数据行里（网页表格没 `<thead>`、Excel 上方有标题行） | `promote_header()`：列名全是 0/1/2 就往下载找「命中 ≥2 个字段关键词」的行当表头 |
| 合并单元格，学院/专业只写在首行 | 对 `college/major_field/major_code/major_name` 向下填充 |
| 单元格里有换行（`081000 信息与通\n信工程`） | 全部去空白与换行 |
| **代码和名称挤在同一格** | 用 `^(\d{6})\s*(.*)` 拆成「专业代码 + 专业名称」两列 |
| 表里同时有「学院代码」和「专业代码」 | `EXCLUDE` 否决词：`major_code` 不许含「学院/院系/单位」 |
| 列名百家争鸣 | `FIELD_RULES` 模糊词表 + 一个字段只认第一个命中的列 |

认不出关键列的表**照样输出**并标 `缺关键列` —— 交给下一层（人）看，而不是丢数据。

## ④ 入库：校验先行

- 专业代码先于专业名称（名字会串，代码不会）
- 同一代码对应多个招生单位时**分行存**，不许合并
- 抽 10% 回原文核对（重点：专业代码、总分、小数点），对不上整表作废
- 冲突两条都留，`note` 互标 —— 见 `school.md` 第十二节

## 研招网（chsi）：能拿什么、不能拿什么

研招网是唯一跨校统一口径的官方源，但入口不统一，实测结论：

| 入口 | 结果 | 处置 |
|---|---|---|
| `/zsml/rs/zys.do`（专业目录查询接口） | **登录前**返回 `请登录`；**用真实登录态（cookie 含 CASTGC）再打，仍然 `请登录`**；在浏览器页面内发 fetch 也 `请登录` | **彻底放弃**：登录态不是它的准入条件，别再把「让用户登录」当解法 |
| `/zsml/a/*.do` 系列 | 401（带 cookie、带 XSRF 头也一样） | 放弃 |
| `/kyzx/zt/lnfsx.shtml`（历年分数线专题） | 页面内嵌 JSON：`tyhxList`（学术学位 14 门）、`ddhxList`（专业学位照顾专业/管理类）、`zhxList`（**34 所自划线院校逐年复试线链接**） | ✅ `scripts/chsi.py` 已封装 |
| `/sch/search.do?dwmc=` | 院校库，给 schId / 所在地 / 院校特性，**不给官网链接** | 只能做名称校验 |

**登录态这条路已经试死了**（2026-10-31 实测）：用户真实登录 → 会话里拿到 `CASTGC` / `JSESSIONID` / `XSRF-CCKTOKEN` → requests 带上 cookie 和 `X-XSRF-TOKEN` 头 → 还是 `请登录`；改用 Playwright 在页面上下文里发同源 fetch，依然 `请登录`。结论：这个接口的前置条件是**服务端会话里的某个特定状态**（大概率要求完成当年报名流程），不是「登录了就能查」。**不要再为此投入。**

```powershell
python scripts/chsi_login.py          # 打开浏览器 → 你登录 → 自动保存会话并自检
python scripts/chsi_login.py --check  # 用已保存会话复检
```

会话存在 `.secrets/chsi_state.json`（已 gitignore），只存 cookie/localStorage，不读密码。留着是因为**研招网其它页面（报名、成绩、调剂）未来可能用得上**，但专业目录不用它。

```powershell
python scripts/chsi.py --national-line 工学      # 国家线（2022-2026，A/B 类 + 单科）
python scripts/chsi.py --self-score 北京         # 34 所自划线院校逐年复试线链接
python scripts/chsi.py --school 北京             # 按名称查 schId
```

**实测校正（值得记住）**：2026 工学 A 类国家线是 **273**，不是 264（264 是 2022 年的）。此前两条非官方来源互相印证了同一个错数 —— **第三方互证 ≠ 真值**，只有官方页能定案。

## 实测记录（2026-10-31）

| 学校 | 形态 | 结果 |
|---|---|---|
| 西电 | PDF（23 份附件） | 全部下载，0 验证码；25 张表认列成功；085404 计划 = 计算机学院 64 + 人工智能学院 12 + 卓越工程师学院 52 + 54 |
| 杭电 | HTML 表（62 行） | 表头提升后认列成功；085404 三处：计算机学院 325（自划线）、工程教育中心 264、圣光机中心 264 |

同一套代码，两种形态，一次跑通 —— 这就是「普适」的判据：**换学校只换 `--seed` 和 `--major`。**

## 已知边界（不假装普适）

1. **扫描件 PDF**：没有文字层时 pdfplumber 返回空 → 转视觉读数（人工或 `read_image`）
2. **要验证码的附件**：脚本只能标 `needs_manual`，必须人工下（吉大、中南）
3. **CAS / SPA 目录**：接口要登录，静态抓只回标题（山大、中南 2027）→ 记 unknown，别硬算
4. **「总分」与「单科」并列的复试线表**：`line` 只认到类型列（自划线/国家线），数值在「总分」列 —— 目前需人工确认，尚未自动配对
5. **公众号里的表**：不在 HTTP 可达范围内，只能人工截图后读图

## 障碍处置：九种卡点

取数失败不是一种情况，是九种。每种的识别信号与固定动作都在这里；**口径问题**（该记 unknown 还是给区间）见 `school.md` 第十一节。

**别硬啃，按顺序降级，并把降级过程写进报告。** 五校实测下来，会卡人的障碍有 9 种，按实测出现频次排：

| # | 障碍 | 识别信号 | 固定动作 | 实测样本 |
|---|---|---|---|---|
| 1 | 表格以图片发布 | 正文 0 个 `<table>`，只有一张 `<img>` | 记下图片 URL → 请用户另存到 `reports/assets/` → `read_image` 读 → 标「官方图片，人工读数」；读不清就 unknown | 深大录取统计表、杭电拟招生计划、山大复试线（1587×8314 长图） |
| 2 | 附件要验证码 | `download.jsp` 返回「请输入验证码下载附件」，HTTP 200 但无内容 | 先找旁路：旧站 `__local/*.pdf` 直链 / 学院站同名文件 / 研招网目录；都不通就请用户手动下载 | 吉大、中南（全校统一入口） |
| 3 | 全站 WAF 412 | 同一域名多个 URL 都 412（不是 404、不是超时） | 同一 URL 最多试 2 次即止；转公众号 / 转载 / 索引降级 | 重邮（连 PDF 附件都 412） |
| 4 | 路径级 WAF | 首页 200、内页 412 —— **只看首页会误判成「不反爬」** | 必须测内页（招生信息页、通知正文页）再下结论 | 重邮学院站：根路径 200，`/xygk/` 412 |
| 5 | 动态目录 / SPA 登录 | 静态抓取只返回标题，或跳到 CAS / 统一认证 | 认输：记 unknown，改从学院站或往年数据取；**不许用推免名单倒推统考名额** | 山大（SPA + CAS）、中南（ASP.NET `MasterView.aspx`）、北师大（目录索引可抓、详情 JS 渲染）、中国政法（`yzbm.cupl.edu.cn` 查询系统） |
| 6 | 公众号人机验证 | HTTP 200 但正文是「环境异常」验证页 | 请用户打开并截图，再用 `read_image`；非官方来源必须在报告里降级标注 | 重邮（分专业计划、复试线都只在这里） |
| 7 | webvpn 重定向 | 302 到 `*.webvpn.*` 域名 | 视为不可达，不要当成反爬反复重试 | 杭电 `cs.hdu.edu.cn`（校内办公网） |
| 8 | 公示期结束即下线 | 标题带「（公示已结束）」，附件链接被撤 | **见到就留档**：表格复制进 `reports/assets/`；补救顺序见下 | 深大、吉大、山大 |
| 9 | 口径陷阱 | 「剩余计划」含专项 / 名单含「不占名额」的行 | 相减前先读说明列 | 吉大（直博与专项推免不占额）、重邮（剩余 221 含 35 个专项） |

**先做两个动作：**

- **测学院站要测内页** —— 首页 200 不等于不反爬（重邮反例），首页 412 也不等于整站废（深大研究生院正常）。
- **拿到「剩余计划」先找说明列** —— 重邮的 221 含 35 个专项，直接当名额会**高估**；吉大的推免名单里直博生不占硕士名额，直接相减会**算少**。两个方向的错都能让你选错学校。

已下线的补救顺序：研招网「历年录取情况统计表」→ 省考试院公示 → 学院复试细则里的「招生指标」→ 往届保存版本。全都不可得 → unknown，写明「需次年 3-4 月重查」。
