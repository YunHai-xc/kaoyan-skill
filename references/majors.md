# 第 1 步：专业画像

> 回答学生第一句话：「这个专业读研那几年具体干什么？之后读博或者工作是什么样？」

这一节不是"学科简介"。**学科简介讲这个领域在研究什么；专业画像讲这个人在读研、读博、毕业三个阶段实际做什么。** 两者混在一起，写出来的东西对选专业没用。

## 一、四块，缺一不可

| 块 | 回答什么问题 | 典型来源 | 自动化程度 |
|---|---|---|---|
| **A 定义** | 这代码是什么、和相邻专业什么关系 | 《学位授予和人才培养学科目录》 | ✅ 离线，`data/major_codes.csv` |
| **B1 共性** | 培养目标、学制、论文要求、实践学分 | 专业学位教指委指导性培养方案、各校培养方案 | ⚠️ 半自动（多为 PDF） |
| **B2 各校差异** | 各校的研究方向清单 | 各校招生专业目录的「研究方向」列 | ⚠️ 能抓（随 check.py 的目录走） |
| **C 往上读** | 有博士点吗、能否硕博连读/直博 | 学校学科建设页、双一流学科名单 | ⚠️ 逐校查 |
| **D 毕业去哪** | 去向、行业、升学比例 | **各校《毕业生就业质量报告》** | ⚠️ 逐校、PDF，需人工定位 |

**D 是最被低估的一块。** 就业质量报告是学校自己每年发的官方文件，含分学院数据；它比任何"前景广阔"的帖子都可核，但需要人工翻 PDF 到对应学院那几页。

## 二、报考资格是硬门槛，排在画像之前

有些专业代码**不是"想不想报"，而是"能不能报"**。最典型的就是法硕：

| 代码 | 名称 | 报考限制 | 初试科目 |
|---|---|---|---|
| 030100 | 法学（学硕） | 无特殊要求 | 政治 + 外国语 + 业务课一 + 业务课二（各校自命题） |
| 035101 | 法律（非法学） | **仅限本科非法学专业** | 101 + 201/202/203 + 398 + 498 |
| 035102 | 法律（法学） | **仅限本科法学专业** | 101 + 201/202/203 + 397 + 497 |

来源：研招网《考研专业全面解析—法学专业》专题（`yzst.chsi.com.cn/yzzt/fx_jx2015`），访问日期 2026-11-06。

**所以「法学本科」的可报范围是 030100 与 035102，035101 直接排除。** 这类限制写在
`data/major_codes.csv` 的 `restriction` 列，`major_profile.py` 会在标题下用 🚫 标出——
**资格不符，后面查多少数据都没用**，必须先确认。

同类需要查资格的还有：部分医学（临床医学不接受非临床本科）、部分教育硕士（限师范类）、
个别工学专业（限本科同门类）。规则都在当年招生简章的「报考条件」，逐校不同。

## 三、粒度：两层，不许混

- **学科层（0854 电子信息）**：给 A 块的定义、与相邻学科的边界。全国统一，查一次用多年。
- **专业代码层（085401）**：给 B2、C、D。**同代码在不同学校做的事可以差很远**，所以 B2 必须按「学校 × 方向」记，不能写一句"该专业主要研究……"糊过去。

## 三、填写纪律（和别的数据一样）

1. **查不到写 `unknown`**，并在缺口清单里写清"去哪找"。
2. **不写无来源判断**："就业前景广阔""行业缺口大"这类，一律不许出现——除非就业质量报告原文这么写，且标了页码。
3. **用户补的每一条都要标**：`用户提供｜来源｜日期`。官方来源标 `官方｜文件或页面｜日期`。
4. **同名不同码要分开**：085404 计算机技术（专硕）和 081200 计算机科学与技术（学硕）是两条画像，不能互相替代。

## 四、怎么用

```powershell
python scripts/major_profile.py --code 085401          # 看画像 + 缺口
python scripts/major_profile.py --code 085401 --init   # 生成骨架，A 块自动填
python scripts/major_profile.py --code 085401 --check  # 只要缺口清单
python scripts/major_profile.py --name 人工智能          # 按名称反查代码
```

输出长这样（`--init` 之后的骨架）：

```
# 085401 新一代电子信息技术（含量子技术等）
## 一句话
085401 … —— 0854 电子信息 · 专业学位，属 08 工学。
## A 定义        ← 已填
## B1 共性       ← unknown ×4，附"去哪找"
## B2 各校差异    ← 空表，等各校目录
## C 往上读      ← unknown ×3
## D 毕业去哪     ← unknown ×3
## 还缺 10 项 —— 去哪找
```

## 五、用户补料

脚本会直接给出**可复制的填空模板**，用户查到后贴回来，写进 `data/majors/<code>.md`：

```
| 是否有一级学科博士点 | 是（0810 信息与通信工程） | 官方｜杭电研究生院学位点页｜2026-11-05 |
```

**下一届学生直接复用这份文件**，不用重查。这也是为什么画像单独成库，而不是塞进每所学校的报告里。

## 六、和「科目」的关系

画像回答"读研干什么"，**不回答"考哪几门"**。后者是第 2 步（专业代码 → 政治/英一二/数一二三/专业课代码），来源是招生目录，逐校不同。

两步不要合并：一个学生可能对"这专业干什么"很确定，但仍然要逐校确认科目（同一代码，有的学校考数一、有的数二）。
