# 生活侧：钱、住、在哪读

择校里最容易漏掉、又最容易后悔的一层。分数线决定能不能上，**这一层决定上了以后三年怎么过。**

它不能并进风险打分里，原因很实在：风险信号回答「今年会不会更难」，生活侧回答「我愿不愿意过这种日子」。**两件事都不是数字，混在一起就会得出「性价比 7.3 分」这种没人看得懂的东西。**

所以单独成节，单独输出，单独给来源等级。

## 一、四个字段

| 字段 | 定义 | 口径陷阱 |
|---|---|---|
| `campus` | 该**院系**所在校区 | 问的是院系，不是学校。同一所学校常常八里台/津南/泰达三处都有 |
| `tuition` | 该**专业**每学年学费（元/生·学年） | 按专业分档，学硕和专硕差一倍以上；非全再翻；联合培养项目单独定价 |
| `dorm_available` | 该专业**是否提供校内住宿** | 这是资格问题，不是条件问题。很多学校**只给学硕**，专硕（含全日制）不给 |
| `dorm_fee` | 住宿费（元/生·学年或区间） | 官方常给区间（如 800—1200），原样抄，别取中位数 |

## 二、三层：能自动化的、能抓但要照抄的、根本抓不到的

| 层 | 内容 | 来源 | 处理 |
|---|---|---|---|
| **L1 结构化** | 院系↔校区对应表、逐专业学费标准、住宿政策条文、学制 | 简章正文第十二条、独立的《各院系所所在校区列表》《学费收费公示表》《学制》 | ✅ 抓下来写成表，可自动化 |
| **L1 但表述模糊** | 住宿费区间、住宿申请制、「培养校区可能与招生学院不一致」 | 同上 | ⚠️ **原样转述**，不许替它总结成确定值 |
| **L4 只在在校生口里** | 几人间、独卫/空调/热水/断电断网、食堂、周边、通勤 | 小红书、B站、贴吧、学长学姐、新生群 | ❌ 不做评分、不做排名，见第四节规则 |

## 三、去哪找（以实测过的南开为例）

南开的做法很典型：**这三类信息全部不在专业目录页上**，而是散在三个地方。

1. **简章正文**：搜「学费」「住宿」「校区」，通常在最后几条。南开 2027 简章第十二条一条写全：住宿申请制、学硕可申请、专硕（含全日制）不提供、住宿费 800—1200。
2. **独立的专题页**：南开研招网「报考指南 → 学费及学制」栏目下挂三份文件——《各院系所所在校区列表》《学费收费公示表》《学制》，**都是 PDF**（`_upload/article/files/...pdf`，由 `pdfsrc` 内嵌）。
3. **奖助体系栏目**：奖学金能不能覆盖学费，直接影响真实成本。

检索模板：

```
site:<研招网域名> 校区 列表
site:<研招网域名> 学费 公示 收费
site:<研招网域名> 学制
site:<研招网域名> 住宿
```

## 四、UGC 的规矩（只有四条，但必须守）

宿舍环境只能靠在校生说，那就按「转述证据」对待：

1. **不做评分、不做排名。** 不出现「宿舍 3/10 分」这种数——一旦给了数，用户会当真，那就是在制造新的信息差。
2. **标时间。** 「2024 年在读生说」和「2025 年翻新后」是两件事，宿舍改造年年有。
3. **标来源类型。** 是官方公告、在校生实拍、还是机构软文，写清楚。
4. **只述不评。** 写「六人间、公共卫浴、23:30 断电」，不写「条件较差」。

如果只找到零星几条，就明说「样本少」，不给结论。

## 五、四个最常见的坑

1. **专硕不给宿舍。** 全日制专硕在很多学校也**不提供**校内住宿（南开明写）。这意味着要按三年租房算钱，而学校周边租金通常远超学费。
   → 择校时把「三年总成本 ≈ 学费×3 + 房租×3」估一遍，这个数经常和「学费贵不贵」的直觉相反。
2. **院系≠校区。** 「南开在天津」没用，计算机在津南区，数学在八里台，两地相距 20 多公里，通勤与生活完全不同。
3. **培养校区会变。** 官方自己都会写「部分学生培养所在校区、住宿所在校区可能与招生学院所在校区不一致，以实际安排为准」。**原样保留这句免责**，别替学校打包票。
4. **联合培养/中外合作单独定价。** 同一所学校里，普通专硕 17500、中外合办项目 80000—100000，差一个数量级，且往往不提供宿舍。

## 六、输出格式

在报告里单列一节，不给总分：

```markdown
## 钱和住

| 项 | 结果 | 来源等级 |
|---|---|---|
| 所在校区 | 津南校区（计算机学院） | L1 官方《校区列表》 |
| 学费 | 17500 元/学年（专硕） | L1 官方《学费公示表》 |
| 是否提供宿舍 | **不提供**（专业学位不安排校内住宿） | L1 简章第十二条 |
| 住宿费区间 | 800—1200 元/学年（仅适用可申请者） | L1 原文区间 |
| 三年现金成本粗估 | 学费 5.25 万 + 租房约 __ 万 | 推算，标注假设 |
| 宿舍内部条件 | 见下一行，不确定 | L4 |
| 在校生说法 | 「六人间/独卫」等，2025 年在读生，样本 3 条 | L4，不代表全部 |

⚠️ 官方原话：「部分学生培养所在校区、住宿所在校区可能与招生学院所在校区不一致，请以实际安排为准。」
```

**「三年现金成本粗估」是这一节最该给的东西**，因为它把学费、住宿、租房三件事合成一个用户能直接比较的数。但它必须标「推算 + 假设」，不能冒充官方数字。
